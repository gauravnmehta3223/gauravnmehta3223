| [Local Outreach Agent](https://github.com/gauravnmehta3223/local-outreach-agent) | A multi-agent system that drafts job-search emails and **cannot send them**. Local 7B models do the narrow generative steps; everything checkable is deterministic code. Fact-grounding against a single source of truth, prompt-injection and PII guardrails mapped to the OWASP LLM Top 10, and a golden-draft eval suite with a per-case regression gate that runs in CI.
